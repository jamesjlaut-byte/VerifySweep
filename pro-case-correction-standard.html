PROFESSIONAL INVESTIGATION STANDARD

VerifySweep Correction and Challenge Standard

How VerifySweep should handle disputed facts, corrections and new evidence in professional investigations.

1. Preserve the original record

Corrections should not erase the history of what was previously documented.

2. Identify the challenged fact

A dispute should specify which statement, source or relationship is being challenged.

3. Evaluate new evidence

New documentation should be assessed using the same source standard applied to the original case.

4. Correct supportable errors

If a factual statement is wrong or no longer supported, update it clearly and record the correction.

5. Keep conclusions proportional

A corrected data point may change the strength of a case. The case should be reevaluated rather than defended automatically.

VerifySweep standard: Evidence should support the exact statement being made. A suspicious indicator is a reason to investigate, not a verdict.
